# Low Level Java

We talked about how ClassLoaders work in Java, especially about how Classes loaded by different ClassLoaders can or can not interact.
We also talked about how Java Agents work, how you can write and use your own.
And we talked about Soft-/Weak-/Phantom-References and how they can be used to point to objects but still make them available for garbage collection.

Examples see here for the agent: https://github.com/kadhonn/talks/tree/main/java-agent
And here for the other topics: https://github.com/kadhonn/talks/tree/main/classloading-unloading-values
